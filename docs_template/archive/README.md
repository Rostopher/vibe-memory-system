# Archive

Use this directory for historical notes, retrospectives, old snapshots, failed
explorations, and completed investigation records.

## Rules

- Keep archived records faithful to their time.
- Extract still-current conclusions into active docs.
- If archive content conflicts with active docs, trust the active docs.
- Do not use archive as a substitute for current status.

## Naming

- `YYYYMMDD_topic.md`
- `YYYYMMDD_retrospective.md`
- `YYYYMMDD_failed_experiment.md`
